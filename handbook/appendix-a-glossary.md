# Appendix A: Glossary

| Term | Definition |
|------|-----------|
| **BARMM** | Bangsamoro Autonomous Region in Muslim Mindanao |
| **BEIS** | Basic Education Information System — DepEd's school information database |
| **CAR** | Cordillera Administrative Region |
| **CHED** | Commission on Higher Education |
| **CMO** | CHED Memorandum Order — the regulatory instrument for HEI programs and standards |
| **DPA** | Data Privacy Act of 2012 (Republic Act No. 10173) |
| **DPO** | Data Protection Officer — the designated privacy compliance officer required under RA 10173 |
| **DepEd** | Department of Education |
| **DICT** | Department of Information and Communications Technology |
| **eGIF** | e-Government Interoperability Framework — DICT's framework for government system integration |
| **E.164** | ITU-T standard for international telephone numbering (format: +[country code][number]) |
| **FLEMMS** | Functional Literacy, Education and Mass Media Survey — PSA survey referenced for school sector codes |
| **HEI** | Higher Education Institution — colleges and universities under CHED jurisdiction |
| **HEMIS** | Higher Education Management Information System — CHED's database of HEIs and students |
| **HUC** | Highly Urbanized City — a city with a population of at least 200,000 and annual income of at least ₱50M, independent of any province |
| **ICC** | Independent Component City — a city independent of a province but whose residents can vote for provincial officials |
| **IDGC** | Inter-Agency Data Governance Committee — the proposed inter-agency body for maintaining these standards |
| **IPBED** | Indigenous Peoples Basic Education Department — DepEd program for IP communities |
| **ISCED** | International Standard Classification of Education — UNESCO framework for comparing education systems across countries |
| **ISCED-F** | ISCED Fields of Education and Training — UNESCO classification of academic disciplines |
| **ISO** | International Organization for Standardization |
| **ITU-T** | International Telecommunication Union — Telecommunication Standardization Sector |
| **LIS** | Learner Information System — DepEd's national learner registry |
| **LRN** | Learner Reference Number — the permanent 12-digit national learner identifier assigned by DepEd |
| **MTB-MLE** | Mother Tongue-Based Multilingual Education — DepEd policy requiring instruction in the learner's first language in Grades K–3 |
| **NC** | National Certificate — TESDA's competency qualification levels (NC I through NC IV) |
| **NCR** | National Capital Region — Metro Manila (region code 13 in PSGC) |
| **NPC** | National Privacy Commission — the regulatory body for RA 10173 |
| **PhilPost** | Philippine Postal Corporation — the agency that assigns and maintains ZIP codes |
| **PhilSys** | Philippine Identification System — the national ID system under RA 11055, administered by PSA |
| **PIA** | Privacy Impact Assessment — a risk assessment required for systems processing sensitive personal information |
| **PIC** | Personal Information Controller — an entity that controls the collection, storage, and processing of personal data |
| **PSGC** | Philippine Standard Geographic Code — PSA's official geocode system for barangays, municipalities, cities, provinces, and regions |
| **PSA** | Philippine Statistics Authority — the national statistical authority; also civil registry and PhilSys administrator |
| **PST** | Philippine Standard Time — UTC+8 |
| **SHS** | Senior High School — Grades 11 and 12 under the K–12 curriculum |
| **SOGIE** | Sexual Orientation, Gender Identity and Expression |
| **SPI** | Sensitive Personal Information — a category of personal data under RA 10173 requiring heightened protection |
| **SUC** | State University or College — a public HEI chartered by national legislation |
| **TESDA** | Technical Education and Skills Development Authority |
| **TESDA TR** | TESDA Training Regulation — the competency standard and qualification framework for a specific TVET qualification |
| **TRACER** | Training Registration, Assessment, and Certification System — TESDA's learner and certification registry |
| **TVI** | Technical-Vocational Institution — a school offering TESDA-registered TVET programs |
| **TVET** | Technical-Vocational Education and Training |
| **UNESCO** | United Nations Educational, Scientific and Cultural Organization |
| **UTC** | Coordinated Universal Time — the global time reference; Philippine Standard Time is UTC+8 |
| **UTF-8** | Unicode Transformation Format — 8-bit encoding standard (IETF RFC 3629); the required encoding for all education sector data systems |
| **VARCHAR** | Variable-length character string — a database data type |
| **WGS 84** | World Geodetic System 1984 — the global coordinate reference system used for GPS and geographic coordinates |
